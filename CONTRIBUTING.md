# 기여 안내 (Contributing)

이 저장소는 IRIS Workspace의 한 부분입니다. 기여 방법은 IRIS 저장소들이 함께 쓰는 문서에 있습니다.

- **[기여 안내](https://github.com/Feynman520/iris-community/blob/main/CONTRIBUTING.md)** — 저장소마다 받는 것이 다릅니다. PR을 내기 전에 0절의 표를 봐 주세요.
- [기여 동의서(CLA)](https://github.com/Feynman520/iris-community/blob/main/CLA.md) · [행동 강령](https://github.com/Feynman520/iris-community/blob/main/CODE_OF_CONDUCT.md) · [운영 규칙](https://github.com/Feynman520/iris-community/blob/main/GOVERNANCE.md) · [상표 정책](https://github.com/Feynman520/iris-community/blob/main/TRADEMARKS.md)
- GitHub 계정이 없다면 홈페이지 의견함으로 보내 주세요: <https://iris-workspace.com/feedback>

**English.** This repository is part of IRIS Workspace. The contribution guide, contributor license agreement, code of conduct, governance and trademark policy are shared across the IRIS repositories: <https://github.com/Feynman520/iris-community>. Each repository accepts different kinds of changes — please read the table in section 0 of the [contribution guide](https://github.com/Feynman520/iris-community/blob/main/CONTRIBUTING.md) before opening a pull request.
